# Featured Nomination — BigHead (Juin 2026)

Pitch à soumettre à l'équipe éditoriale Apple via **App Store Connect → Distribution → App Information → App Store Featuring → Nominate**.

Le formulaire a plusieurs champs courts. Voici les textes prêts à coller.

---

## Pitch principal (1-2 paragraphes)

### Version FR

> **BigHead est l'app de quiz culture générale qui réinvente le duel asynchrone façon Trivia Crack — pensée d'abord pour le marché francophone.**
>
> Lancée en février 2026, BigHead propose plus de 10 000 questions réparties dans 13 catégories, avec un contenu hebdomadaire dynamique généré toutes les semaines : un quiz thématique le vendredi (Belgique, Espace, Japon…) et un quiz d'actualité chaque dimanche. Le mode duel async 1v1 (10 questions, 48h pour répondre) vient d'être lancé et constitue notre différenciateur clé sur le marché FR/EN.
>
> Disponible en français et anglais, l'app combine défi quotidien, tournois hebdomadaires, mode aventure, quiz audio (sons, instruments, hymnes) et système d'achievements. Premium via abonnement RevenueCat depuis mars 2026. Architecture moderne : Expo SDK 54, Supabase backend, EAS Update pour les OTA.

### Version EN

> **BigHead is the trivia app that reinvents Trivia Crack's async duel model — built first for the French-speaking market, now bilingual.**
>
> Launched February 2026, BigHead offers 10,000+ trivia questions across 13 categories, with fresh weekly content: themed quiz on Fridays (Belgium, Space, Japan…) and a weekly news quiz on Sundays. Our just-shipped async 1v1 duel mode (10 questions, 48h to answer) is our key differentiator on the FR/EN market.
>
> Available in French and English, the app combines daily challenges, weekly tournaments, adventure mode, audio quiz (sounds, instruments, anthems) and an achievement system. Premium subscription via RevenueCat since March 2026. Modern stack: Expo SDK 54, Supabase backend, EAS Update OTA.

## What makes BigHead unique? (bullet points pour la section USP)

- **Async 1v1 duels (Trivia Crack model)** — first FR-native implementation, with social mechanics built-in
- **Live-updated content** — themed and news quizzes generated weekly via AI pipeline (Anthropic Claude)
- **Bilingual native** — full FR + EN content parity, not just translations
- **13 deep categories** — including underrepresented topics like audio quiz (instruments, anthems, sounds)
- **Indie-built, premium-polished** — single founder, ships weekly via EAS Update
- **Strong viral loop** — shareable duel invite links with deep linking (Universal Links)

## Procédure

1. **App Store Connect → My Apps → BIGHEAD**
2. **Distribution → App Store Featuring → Nominate**
3. Coller le pitch + cocher les catégories
4. Soumettre — pas de notification, c'est l'équipe éditoriale qui décide silencieusement
5. **Best time to nominate** : juste après un milestone (release majeure, feature notable, traction notable)

**Recommandation** : nominer **après** que la 1.2.3 (avec async duel) soit live sur le store + que les 4 In-App Events soient approuvés. C'est le pic de signaux positifs pour Apple.
